# Nether & End Rain (Fabric 1.20.1)
Real rain in the Nether and the End.
- Follows the Overworld weather cycle (natural rain starts/stops by itself).
- /weather rain | clear | thunder works from any dimension.
- Needs Fabric API. Install on the server too (multiplayer).
